## 🛡️ Anti-Scam Payment Verification System
To protect the pantry from fake order submissions, the system features a **2-layer anti-scam lock**:
1. **Mandatory 12-Digit Paytm UTR / UPI Reference ID**:
   - Students scanning the official Paytm QR must enter the 12-digit UPI Ref ID from their payment screen before an order can be confirmed.
   - The Manager Dashboard (`admin.html`) matches this UTR against real-time Bank/Paytm SMS notifications.
2. **Pay on Handover (Doorstep Cash/UPI)**:
   - Students can opt to pay upon arrival at their room door in 2–3 minutes. Snacks are only handed over once payment is received.
